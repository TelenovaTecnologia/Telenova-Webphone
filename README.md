# Telenova Webphone

Documentação oficial de integração do Webphone da Telenova.

O Webphone permite integrar recursos de telefonia diretamente a sistemas externos, como CRMs, ERPs e outras aplicações web.

## Sobre

Este repositório contém a documentação pública necessária para integrar e configurar o Telenova Webphone.

Aqui serão documentados:

- autenticação;
- integração do Webphone;
- API de configuração;
- parâmetros disponíveis;
- exemplos de uso;
- respostas e erros da API.

## Documentação

A documentação detalhada está disponível na pasta [`docs`](./docs).

## Suporte

Em caso de dúvidas sobre a integração, entre em contato com a equipe da Telenova Tecnologia.
